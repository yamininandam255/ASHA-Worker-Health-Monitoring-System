# ASHA-Worker-Health-Monitoring-System
Mobile-Based Health Monitoring System for ASHA Workers using Flutter and Node.js

## Project Overview
Developed a mobile-based health monitoring application designed to support ASHA workers in managing and monitoring health-related information. The application uses Flutter for cross-platform mobile development, Node.js for backend services and MongoDB for data storage.

Firebase Authentication is integrated to provide secure user login and authentication.

## Technologies Used
- Frontend: Flutter
- Backend: Node.js
- Database: MongoDB
- Authentication: Firebase Authentication

## Key Features
- Cross-platform mobile application.
- Secure user authentication.
- Health information management.
- Backend API integration.
- MongoDB-based data storage.
